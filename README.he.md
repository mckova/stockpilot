# Stockpilot: מלאי למחסן אחד ולחנויות שהוא מזין, עם מתכנן AI ששואל לפני שהוא פועל

מערכת פול סטק לעסק עם מחסן מרכזי ושני סניפים. Claude קורא את מצב המלאי החי כל בוקר, מציע הזמנות רכש והעברות, מנהל חותם, ורק אז משהו זז.

## מה יש בה

- **מתכנן (AI)**: סוכן Claude Opus 5.5 עם 11 כלים קשיחים על הנתונים החיים. מריץ סקירת בוקר או עונה על שאלות בעברית ובאנגלית. כלי הכתיבה היחידים שלו הם כלי "הצעה": ההצעות נכנסות לתור חתימה, ורק אישור של מנהל יוצר מסמך טיוטה.
- **קליטת תעודת משלוח (AI)**: מעלים צילום או PDF של תעודת המשלוח בזמן קבלת סחורה. Claude קורא אותה למבנה JSON קשיח, טופס הקבלה מתמלא בכמויות, אצוות ותוקף, וכל פער מסומן: עודף, שינוי מחיר, שורה חסרה, ספק שונה מההזמנה. שום דבר לא נרשם עד שאדם מאשר.
- **בית**: רשימת עבודה במקום דשבורד: הצעות שמחכות לחתימה, פריטים מתחת למינימום, אצוות שפג תוקפן בשבועיים הקרובים, הזמנות למשלוח. בכל שורה הפעולה שלה.
- **קופה**: קופת סניף עם סריקת ברקוד, כל מכירה היא תנועה ביומן, הוותיק ביותר יוצא ראשון.
- **מנוע מלאי**: תנועות דו-צדדיות בין מיקומים, יומן שלא נמחק לעולם, אצוות ו-FEFO, עלות ממוצעת נעה.
- **רכש, מכירות, העברות וספירות** עם מכונות מצבים מלאות.
- **חידוש מלאי**: כללי מינימום/מקסימום לכל אתר, קנייה מספק או העברה מהמחסן.
- **ביקוש**: תחזית, מלאי ביטחון, נקודת הזמנה, ימי כיסוי, ABC ומלאי מת.
- **הרשאות**: מנהל מערכת, מנהל, מחסנאי.

## עיצוב

לוחות זכוכית מושלגים על רקע מרווה וחול, ירוק אורן אחד לפעולות, טבלאות פשוטות לעבודה ותפריט כדורי. צהוב וכתום מופיעים רק כנתונים (מתחת למינימום, פג תוקף, מחכה לחתימה). פירוט ב-[DESIGN.md](DESIGN.md).

## הרצה

ראו את [README.md](README.md). בקצרה: `python -m app.seed`, ואז `uvicorn app.main:app` ו-`npm run dev`. כדי להפעיל את ה-AI צריך להגדיר `ANTHROPIC_API_KEY`.
