# Stockpilot: מערכת AI נייטיב לניהול מחסן, חנויות ומלאי

מערכת פול סטק לעסק עם מחסן מרכזי וכמה סניפים, עם סוכן Claude מובנה שקורא את מצב המלאי בזמן אמת ומציע את הצעדים הבאים.

## מה יש בה

- **Copilot**: צ'אט (עברית או אנגלית) עם סוכן Claude Opus 5.5 ו-11 כלים על הנתונים החיים. הוא מנתח ומציע הזמנות רכש, העברות בין סניפים ושינויי כללי הזמנה, וההצעות נכנסות לתור אישור. רק מנהל מאשר, ואז נוצר מסמך טיוטה.
- **מנוע מלאי**: תנועות דו-צדדיות בין מיקומים, יומן תנועות שלא נמחק לעולם, הזמנות שמורות (רזרבציה).
- **אצוות ותוקף**: ליקוט FEFO (פג תוקף ראשון יוצא ראשון) והתראות תוקף.
- **רכש, מכירות, העברות וספירות מלאי** עם מכונות מצבים מלאות.
- **חידוש מלאי**: כללי מינימום/מקסימום לכל אתר, קנייה מספק או העברה מהמחסן.
- **תובנות**: תחזית ביקוש, מלאי ביטחון, נקודת הזמנה, ימי כיסוי, ניתוח ABC ומלאי מת.
- **הרשאות**: מנהל מערכת, מנהל, מחסנאי.

## הרצה

ראו את [README.md](README.md). בקצרה: `python -m app.seed`, ואז `uvicorn app.main:app` ו-`npm run dev`. כדי להפעיל את ה-Copilot צריך להגדיר `ANTHROPIC_API_KEY`.
